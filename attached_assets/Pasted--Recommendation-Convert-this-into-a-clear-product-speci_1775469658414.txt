# Core Business Rules (Non-Negotiable)

These rules must be enforced in backend and frontend.

### Rule 1 — Targets Freeze After CRO Approval

Once CRO approves:

* targets become read-only
* no edits allowed
* no overwriting
* no recalculation
* only revenue affects achievement

Targets become the **denominator of performance**.

---

### Rule 2 — Achieved Revenue Comes Only from Revenue Entries

Achieved must be calculated from:

```
revenue_entries table
```

Not from:

* deal stage
* proposal
* mail confirmation
* pipeline

Mail Confirmed is not achieved.

Only RO Received → Revenue Entry → Achieved.

---

### Rule 3 — My Plan Drives Pipeline

Pipeline must not be created manually.

Pipeline should come from:

```
My Plan → Touchpoints → Deal Stage → Pipeline
```

No duplicate deal creation logic.

---

### Rule 4 — Role-Based Access

System must read from:

```
otv_users.role
otv_users.region
```

and automatically show correct screens.

No manual switching.
