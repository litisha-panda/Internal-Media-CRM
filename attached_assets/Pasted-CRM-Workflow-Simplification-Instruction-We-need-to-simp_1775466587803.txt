CRM Workflow Simplification Instruction

We need to simplify the CRM and align the frontend with the business workflow.
Right now there are too many modules (War Room, Revenue Tracker, My Plan, My Targets, etc.) which creates confusion.

The system should follow a clear linear workflow.

Core Workflow

The CRM should operate like this:

1. Admin uploads targets
2. Users signup and roles are assigned
3. System assigns targets automatically
4. User logs in and sees their targets
5. User creates their plan
6. Plan creates pipeline
7. Tasks and touchpoints drive execution
8. Revenue gets logged
9. Leadership monitors performance

Everything should support this flow.
