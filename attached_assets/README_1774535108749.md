# OTV CRM — Replit Deployment Guide

## Files to upload
```
/
├── .replit
├── package.json
├── vite.config.js
├── index.html
├── server.js
└── src/
    ├── main.jsx
    └── SalesCommandCenter.jsx   ← your main app file
```

## Step-by-step

### 1. Create a new Replit
- Go to replit.com → Create Repl
- Choose **Node.js** template
- Name it: `otv-crm`

### 2. Upload files
- Delete the default `index.js` Replit creates
- Upload all files from this folder, maintaining the folder structure
- Put `SalesCommandCenter.jsx` inside the `src/` folder

### 3. Add your Anthropic API key
- In Replit, click the **Secrets** tab (lock icon in left sidebar)
- Add a new secret:
  - Key: `ANTHROPIC_API_KEY`
  - Value: your Anthropic API key (starts with `sk-ant-...`)

### 4. Run
- Click the green **Run** button
- Replit will run: `npm run build && npm start`
- First run takes ~2 minutes (installing deps + building)
- Your app will be live at `https://otv-crm.YOUR-USERNAME.repl.co`

### 5. Update the React app to use the proxy
In `SalesCommandCenter.jsx`, find any `fetch("https://api.anthropic.com/v1/messages"` calls
and change them to `fetch("/api/claude"` — this routes through your server-side proxy
so the API key is never exposed in the browser.

## Sharing with the team
Once deployed, share the Replit URL. Team members:
1. Go to the URL
2. Click **Continue with Email**
3. Enter their @odishatv.com email + create a password
4. You see their request in Admin → Access Management
5. You assign their role (Sales Rep / Region Head / etc.) and click Approve
6. They're in
