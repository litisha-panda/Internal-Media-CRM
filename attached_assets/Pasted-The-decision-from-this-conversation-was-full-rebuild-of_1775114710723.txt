## The one rule that everything depends on

```
ACHIEVED = sum of revenueEntries only.
Never from deal stages.
Never from deal amounts.
Never from d.amount or d.outcome.
One entry in Revenue Log = one credit to ACHIEVED. Nothing else.
```

## Section 3 — The four numbers

One shared function. Called from every screen. Never inlined separately.

```javascript
const calcNumbers = (repIds, fiscalYear, quarter) => {
  // Filter revenue entries for this rep set and period
  const entries = revenueEntries.filter(e =>
    repIds.includes(e.repId) &&
    (e.fiscalYear === fiscalYear) &&
    (quarter === "FY26 Annual" || e.quarter === quarter || e.quarter === "FY26 Annual")
  )

  // Filter client accounts for this rep set
  const accounts = clientAccounts.filter(a =>
    repIds.includes(a.repId) &&
    a.fiscalYear === fiscalYear &&
    a.approvalStatus === "Approved"
  )

  const totalTarget = accounts.reduce((s,a) => s + (a.annualTarget||0), 0)

  // ACHIEVED = revenue entries only. Never from stages. Never from d.amount.
  const achieved = entries.reduce((s,e) => s + (e.amount||0), 0)

  // COMMITTED = accounts at Mail Confirmed stage
  const committed = accounts
    .filter(a => a.currentStage === "Mail Confirmed")
    .reduce((s,a) => s + (a.annualTarget||0), 0)

  // IN PLAY = accounts at In Discussion or Negotiation
  const inPlay = accounts
    .filter(a => ["In Discussion","Negotiation"].includes(a.currentStage))
    .reduce((s,a) => s + (a.annualTarget||0), 0)

  const shortfall = Math.max(0, totalTarget - achieved - committed - inPlay)

  return { totalTarget, achieved, committed, inPlay, shortfall }
}
```

Use `calcNumbers()` on every single screen that shows these numbers. No exceptions. No inline calculations.

## Section 4 — Deal stages

Stage changes in ONE place only: the touchpoint log form when touchpointType = "Deal Meeting". Remove all inline stage dropdowns from Revenue Tracker, deal tables, and everywhere else.

```
Prospect      → no pipeline impact, no escalation
In Discussion → enters IN PLAY via calcNumbers()
Negotiation   → stays IN PLAY, higher urgency in War Room
Mail Confirmed → moves to COMMITTED via calcNumbers()
               → action items section hidden in log form
               → show "Waiting for RO? Set a reminder (3/5/7 days)"
RO Received   → set automatically when revenue logged, never manually
               → moves amount to ACHIEVED via calcNumbers()
Lost          → mandatory loss reason, removed from all calculations
```

When rep logs revenue for a client → set that clientAccount.currentStage = "RO Received" automatically.

## Section 6 — Action item routing

Route automatically on touchpoint submit. No manual routing.

```
Approval needed
  → Create internalReq with type="Approval", route to assignedTo person
  → Appears in assignee's Approvals tab AND My Tasks
  → Rep sees it in Internal Requests as "Approval sent to [Person] — Pending"
  → SLA: 48h. Breach → status="Escalated", move to Escalations tab of assignee, manager notified

Document needed
  → Create task for assignee
  → Title: "[Doc needed] — [Client] — [Details] — by [Date] — from [Rep]"
  → Rep sees in Internal Requests as sent
  → SLA: 48h. Breach → Escalations

Attend a meeting
  → Create plan entry for assignee as unscheduled meeting request
  → Assignee must confirm date. On confirm → appears on both people's My Plan
  → Rep sees in Internal Requests as awaiting confirmation
  → SLA: 48h to confirm. Breach → Escalations

Introduction needed
  → Create task for assignee
  → Assignee's RH gets informational note in War Room only
  → No SLA

Flag for follow-up
  → Create task for Legal or Finance only
  → Rep sees status in Internal Requests

Self
  → Create task for rep only
  → No internalReq created
  → No one else notified
```

**Missed due date:** Any action item past due date → status = "Escalated" → moves to Escalations tab of assignee → manager sees in War Room "Overdue in my team."

**Internal Requests badge:** Count = only items where assignedTo = current user AND status = "Open". Items sent to others do not count toward badge.

## Section 18 — Escalation engine

Run on every page load. Check all four triggers.

**Trigger 1:** clientAccounts where currentStage in ["In Discussion","Negotiation","Mail Confirmed"] AND daysSince(lastDealMeetingDate) >= threshold
- Day 7: At Risk card on rep's My Plan
- Day 10: alert in RH War Room
- Day 14: create task in RH My Tasks "Intervene — [Client] — [Rep]"

**Trigger 2A:** clientAccounts where rep has 4+ touchpoints of type "Deal Meeting" in last 30 days AND currentStage same as 30 days ago → RH War Room alert

**Trigger 2B:** reps where touchpoints in current calendar month < 15 → RH War Room alert on last day of month

**Trigger 3:** actionItems where dueDate < today AND status = "Open" → set status = "Escalated", notify assignee, notify assignee's manager

All thresholds from adminConfig. Configurable without code changes.
