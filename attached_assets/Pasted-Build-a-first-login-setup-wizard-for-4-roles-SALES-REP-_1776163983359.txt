Title: "Welcome! Let's set up your profile"
Fields:
- Full Name (text, required)
- Region (dropdown: North, South, West 1, West 2, Odisha, Digital, East)
On Continue: PATCH /api/users/me with { name, region }

STEP 2 — Review Your Team's Targets
Title: "Your team has submitted targets for approval"
- Query target_submissions where status = 'Pending RH' AND rep's manager_id = current user's id
- If no submissions: show "No targets pending yet. You'll approve them from the Target Approvals tab." with a Continue button
- If submissions exist: show table with columns:
  Sales Rep | Agency | Client | Brand | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec | Q1(auto) | Q2(auto) | Q3(auto) | Q4(auto) | Annual(auto) | Action
- Action per row: green Approve button + red Reject button
- Reject opens inline remarks input + Confirm button
- Approve: update status to 'Pending NSH'
- Reject: update status to 'Pending Rep', save remarks, create in-app notification for the rep: "Your target for [Client] was rejected by [RH Name]: [remarks]"
- Continue button appears once at least one row has been actioned (or immediately if empty state)

STEP 3 — Done
Title: "You're ready to go!"
Body: "Approved targets move to NSH for final sign-off. You can review new submissions anytime from the Target Approvals tab."
Button: "Start Tour" → fires guided tour
